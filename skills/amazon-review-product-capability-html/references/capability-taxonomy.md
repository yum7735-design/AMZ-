# Product-capability taxonomy

Use the following normalized capability labels when the linked user need and review evidence support them. These labels name what a product must be able to do, not how it is constructed.

| Category | Preferred label | Valid trigger |
|---|---|---|
| Shrinking | Tight Shrink Fit / 紧密收缩贴合 | Loose or insufficient post-shrink fit; explicit need for tight stable coverage |
| Shrinking | Uniform Shrinking / 均匀收缩 | Uneven or incomplete shrink evidence; need explicitly includes uniform coverage |
| Shrinking | Predictable Shrinking / 可预测收缩表现 | Excessive/uncertain heating or slow shrink creates use difficulty |
| Sealing | Reliable Moisture / Water Sealing / 可靠防潮密封 | Confirmed sealing failure, moisture concern, or explicit water-sealing need |
| Sealing | Long-term Seal Integrity / 长期密封完整性 | Need/evidence concerns retention of a seal over use |
| Adhesion | Long-term Adhesive Bond Retention / 长期粘合保持 | Adhesive absent, insufficient, or fails to retain tubing on the connection |
| Insulation | Electrical Insulation / 电气绝缘保护 | Explicit exposed-conductor or insulation evidence only |
| Mechanical Protection | Mechanical Protection / 机械保护 | Evidence of inadequate physical protection, abrasion, impact, or strain damage |
| Temperature Resistance | High-temperature Stability / 高温稳定性 | Tubing heat damage/deformation plus thermal-stability need |
| Durability | Tear & Crack Resistance / 抗撕裂和开裂能力 | Actual tearing, splitting, or cracking |
| Material Handling | Post-Shrink Flexibility / 收缩后柔韧性 | Evidence that post-shrink rigidity impairs use |
| Fit & Compatibility | Connector Clearance & Size Compatibility / 连接器通行与尺寸适配 | Cannot fit or slide over target connector/cable shape |
| Size & Length | Multiple Diameter Options / 多规格直径覆盖 | Explicit missing size range, diameter gaps, or unsuitable size mix |
| Size & Length | Appropriate Piece Length / 适宜连接覆盖长度 | Explicit piece length is inadequate for the target connection |
| Identification & Organization | Clear Size Identification / 清晰规格识别 | Hard to identify/select the needed size |
| Identification & Organization | Organized Storage / 有序收纳 | Compartments fail to retain or separate pieces; storage prevents access |
| Product Consistency | Consistent Product Performance / 一致的产品表现 | Actual cross-piece variation, pre-shrunk pieces, duplicate/missing declared pieces |

Avoid these unsupported shortcuts:

- Do not convert a theoretical outdoor use into UV resistance.
- Do not convert a boat application into water sealing without sealing evidence.
- Do not convert a positive “does not melt/crack” claim into a pain-driven capability.
- Do not convert a request for a better size range into a specific shrink ratio.
