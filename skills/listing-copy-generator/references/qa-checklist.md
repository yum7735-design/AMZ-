# QA Checklist

Run this checklist before delivering the output.

## Content checks

- Confirm the title leads with the brand when the user requires it.
- Confirm each title stays within the required character limit.
- Confirm the item-highlight count matches the user request.
- Confirm each item highlight stays within the required character limit.
- Confirm each bullet addresses a different demand or buying question.
- Confirm backend search terms supplement uncovered keywords instead of repeating title terms.

## Amazon-style checks

- Remove banned marketing words like `best`, `premium`, `amazing`, `discount`, and `sale`.
- Remove fake urgency, ranking claims, and promo language.
- Avoid repeating the same keyword cluster across title, highlight, and bullets unless it is essential.
- Avoid unsupported superlatives or certification-like claims unless the user supplied proof.

## VOC checks

- Trace each key claim back to the needs map or keyword-demand matrix.
- Translate features into user benefits, not bare specs only.
- Keep high-intent keywords in the title first, then highlights, then bullets, then backend terms.

## Delivery checks

- Verify the CSV tables open cleanly.
- If exporting `.xlsx`, confirm the `Item Highlights` sheet row count matches the CSV.
- If the workbook file is locked, export under a new filename instead of overwriting the old one.
