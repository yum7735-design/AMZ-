# Creative Proof Patterns

Choose the pattern that makes the verified value visible.

| Pattern | Best for | Minimum proof | Avoid when |
|---|---|---|---|
| Result inspection | Quality, finish, fit, clean output | Macro view plus a stated inspection criterion | The outcome requires an invisible technical test |
| Match / set / operate | Configuration-sensitive tools | Actual material + setting + complete action | Correct settings are unconfirmed |
| Task recovery | Repair and maintenance tools | Genuine task sequence and final non-misleading state | The scene implies a safety outcome that is untested |
| Structure reveal | Mechanism or adjustment design | Observable moving part / interface | Structure does not explain a user benefit |
| Context switch | Multiple established scenes | One concrete job per scene | The category merely claims the scene without support |

For a proof gap, specify the shot/test needed. Do not replace the gap with animated graphics or copy.
