# 中文默认输出模板

当用户主要使用中文，且希望直接拿去给运营、设计、SEO 或产品团队协作时，优先按这套中文结构输出。

目标：
- 章节名中文化
- 表头中文化
- 结论先服务 Listing 执行，不写空泛理论
- 证据不足时明确写 `证据不足`

## 推荐标题

默认标题可写成：

`[品牌/产品线] 关键词 × 用户需求矩阵`

例如：
- `成卷热缩关键词 × 用户需求矩阵`
- `宠物梳关键词 × 用户需求矩阵`

## 中文章节顺序

1. 产品定位总结
2. 用户需求总结
3. 关键词洞察总结
4. 关键词 × 需求矩阵
5. 关键词 × 页面沟通矩阵
6. 图片需求矩阵
7. 五点卖点映射
8. 标题策略
9. A+ 策略
10. SEO 覆盖建议
11. 缺失需求分析
12. 优化优先级

## 中文章节写法建议

### 1. 产品定位总结

建议固定拆成四小段：
- 产品定位
- 产品价值
- 核心竞争力
- 与普通产品的最大区别

### 2. 用户需求总结

建议固定回答五个问题：
- 谁在购买
- 为什么购买
- 在什么地方使用
- 最关心什么
- 最担心什么

### 3. 关键词洞察总结

重点不是重复关键词，而是解释：
- 关键词背后的真实任务
- 关键词背后的真实担忧
- 哪些词适合做主沟通
- 哪些词虽然有流量但会带偏认知

## 中文表格模板

### 关键词 × 需求矩阵

| 关键词 | 搜索意图 | 用户需求 | 使用场景 | 对应痛点 | 购买驱动 | 优先级 |
| ------ | -------- | -------- | -------- | -------- | -------- | ------ |

优先级建议：
- `P0`：必须优先处理
- `P1`：重要但不是第一优先
- `P2`：可后置优化
- `排除`：不建议放入当前主策略

### 关键词 × 页面沟通矩阵

| 关键词 | 页面位置 | 原因 |
| ------ | -------- | ---- |

页面位置建议统一中文：
- 标题
- Bullet 卖点
- 图片
- A+ 页面
- 后台搜索词
- 不建议使用

### 图片需求矩阵

| 用户需求 | 推荐图片 | 原因 |
| ------- | -------- | ---- |

图片命名建议偏执行化，例如：
- 收缩前后对比图
- 尺寸适配图
- 场景应用图
- 结构剖面图
- 使用边界图

### 五点卖点映射

| 卖点条目 | 对应需求 | 对应关键词 |
| -------- | -------- | ---------- |

默认可按：
- Bullet 1：核心价值/结果
- Bullet 2：功能或规格优势
- Bullet 3：场景与适配
- Bullet 4：品质/专业/信任
- Bullet 5：包装内容、使用边界或支持说明

## 中文措辞偏好

优先使用：
- `购买驱动`，少用过学术化表达
- `页面位置`，少用 `communication placement`
- `使用场景`，少用 `scenario mapping`
- `缺失需求分析`，少用 `gap analysis`
- `优化优先级`，少用笼统的 `next steps`

避免：
- 大段泛化 SEO 理论
- 空泛的“提升用户体验”“强化品牌认知”但没有对应证据
- 没有映射到 Listing 位置的结论

## 中文结论段模板

结尾建议用 3 句内总结：

1. 这个产品真正卖的是什么结果
2. 标题/Bullet/图片最该先解决什么问题
3. 哪些关键词该重点放大，哪些关键词该避免误用

示例模板：

`这个产品真正卖的不是[表面产品形态]，而是[用户最终想得到的结果]。`

`当前 Listing 优先要解决的不是词不够多，而是[定位不清 / 尺寸不清 / 场景不清 / 结果证据不足]。`

`后续优化应优先放大[核心词/功能词/场景词]，并避免[误导词/跨品类词/错误规格词]带来的错误预期。`

## HTML 或正式交付时

如果用户要求 HTML、文档化报告或展示版输出：
- 保持这 12 个中文章节名不变
- 保持表头中文化
- 保持矩阵逻辑不变
- 不要因为格式升级而改变证据口径
