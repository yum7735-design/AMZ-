# Output Structure

Use this structure when the user asks for a full keyword-demand analysis deliverable.

## Required Sections

1. Product Positioning Summary
2. Demand Summary
3. Keyword Insight Summary
4. Keyword × Demand Matrix
5. Keyword × Communication Matrix
6. Image Demand Matrix
7. Bullet Mapping
8. Title Strategy
9. A+ Strategy
10. SEO Coverage Recommendations
11. Missing Demand Analysis
12. Optimization Priority

## Required Matrix Columns

### Keyword × Demand Matrix

| 关键词 | 搜索意图 | 用户需求 | 使用场景 | 对应痛点 | 购买驱动 | 优先级 |
| ------ | -------- | -------- | -------- | -------- | -------- | ------ |

Requirements:
- Every keyword row must map to all columns.
- Exclude or flag misleading keywords when needed instead of pretending they fit.

### Keyword × Communication Matrix

| 关键词 | 页面位置 | 原因 |
| ------ | -------- | ---- |

Typical positions:
- 标题
- Bullet 卖点
- 图片
- A+ 页面
- 后台搜索词
- 不建议使用

### Image Demand Matrix

| 用户需求 | 推荐图片 | 原因 |
| ------- | -------- | ---- |

Do not design the image itself unless explicitly asked. Map the demand to the image job.

### Bullet Mapping

| 卖点条目 | 对应需求 | 对应关键词 |
| -------- | -------- | ---------- |

Default pattern:
- Bullet 1: core value/result
- Bullet 2: feature or specification logic
- Bullet 3: usage scenario
- Bullet 4: trust/quality/professional result
- Bullet 5: usage boundary, packaging, or support logic

## Strategy Sections

### Title Strategy

State:
- which keywords the title should cover
- which demands the title should cover
- which purchase drivers the title should cover
- why that structure matters

### A+ Strategy

State:
- which demands fit A+ better than the title
- which keywords should stay out of the title
- what belongs in brand story
- what belongs in FAQ

### SEO Coverage Recommendations

State:
- the primary SEO anchors
- support terms suitable for bullets, images, A+, and backend
- risky or misleading terms that should be avoided or isolated

### Missing Demand Analysis

List:
- real buyer needs visible in demand/VOC inputs but weak in the keyword set
- areas where evidence is insufficient and more data is needed

### Optimization Priority

Use:
- `P0` for changes that fix positioning, major conversion risk, or large SEO gaps
- `P1` for important but non-blocking improvements
- `P2` for later experiments or low-confidence extensions
