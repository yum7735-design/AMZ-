# Amazon B2B 父体广告花费占比

当用户需要统计“企业购广告花费 ÷ 广告花费”时使用本技能。将广告记录的 ASIN 映射回产品表父体 ASIN，按父体归集并可同时按产品线汇总。结果必须可复核，不能把广告活动、广告名称和广告组合三个字段混用。

## 开始前

1. 确认输入包含产品表和广告报告。先读表头和少量样本，确认字段映射；字段别名见 [字段与口径](references/field-and-policy.md)。
2. 对 `.xlsx` 读写使用 `spreadsheets` 技能及其 Artifact Tool 流程。保留原始源文件，不直接改写用户输入。
3. 如用户未指定阈值，使用 5%。如用户未指定企业购识别字段，使用“广告活动包含 `企业购`”。任何不同口径须先写入输出的“口径说明”。

## 必须遵循的归集规则

- 产品表通过子体 `ASIN` 映射到 `父ASIN`；广告记录中出现父体 ASIN 时也应能直接映射。
- 先从广告 ASIN 字段提取唯一的十位 ASIN。若一条记录包含多个 ASIN，则将花费按 ASIN 数量**等额分摊**，再将分摊金额归集到父体。未映射 ASIN 的份额保留在对账差异中，不挪给已映射 ASIN。
- 父体的“定位”值精确等于 `清货` 或 `清库存` 时，整个父体不纳入结果。除非用户指定，否则不要按品名或广告文字模糊判断清货。
- 只剔除用户明确给出的广告组合，且必须在 `广告组合` 字段做**精确匹配**。不要因广告名称、广告活动、广告类型或部分关键词相似而额外剔除。常用但非默认的两个剔除项是 `店铺-品牌广告` 与 `焊锡/BHT/热缩/工具/铜鼻SB广告`。
- 企业购判断与剔除彼此独立：只有广告活动字段包含 `企业购` 的、且未被排除的记录，才计入企业购广告花费。
- 企业购花费占比始终以同一父体或产品线范围内的 `企业购广告花费 / 广告花费` 计算；不要平均行级比例。

## 执行

优先运行 `scripts/analyze_parent_spend_share.py` 生成可审计 JSON；它需要产品表、广告表、输出路径和用户确认的剔除组合。示例命令与返回字段见 [字段与口径](references/field-and-policy.md)。脚本只进行读取和写入分析 JSON，不覆盖源 Excel。

若需要 Excel 交付，基于该 JSON 用 Artifact Tool 创建或更新一个新工作簿。最小工作表结构为：

1. `达成清单`：仅显示占比达到阈值的父体 ASIN、父体品名、产品线、广告花费、企业购广告花费、占比。
2. `全部父体汇总`：显示全部有花费且符合范围的父体，便于核查未达标产品。
3. `广告分摊明细`：保留原广告行号、原始 ASIN、ASIN 数量、父体 ASIN、广告组合、广告活动、分摊花费、是否企业购。
4. `剔除广告记录`：保留所有因精确广告组合规则剔除的行及理由。
5. `口径说明`：记录周期、阈值、企业购识别字段、清货规则、剔除组合、ASIN 等额分摊与对账结果。

当用户指定产品线时，添加 `产品线汇总`，包含产品线、广告花费、企业购广告花费、企业购花费占比、有花费父体数和分摊广告记录数。对占比不低于阈值的单元格做条件高亮。

## 校验与交付

- 对账：广告总花费 − 精确剔除花费，应等于父体已归集花费 + 清货父体花费 + 空 ASIN 花费 + 未映射 ASIN 份额 + 对账差异。对账差异应为零（允许合理浮点误差）；否则在“口径说明”和回复中披露。
- 不把同一父体重复累计到多个产品线。若有花费父体对应多个产品线，单独列出并请用户确认归类；在确认前不要把它们纳入产品线合计。
- 检查父体达标数、产品线达标数、金额和百分比格式。占比用 `0.0%`，货币使用报告币种并保留两位小数。
- 新增或修改 Excel 后，运行重算、关键范围检查、公式错误扫描和渲染检查。源表被占用时，另存为明确标注的结果文件，不要强行覆盖。

## 边界

本技能回答的是父体/产品线层面的企业购广告投入占比，不等同于企业购销售额、B2B 订单或 B2B 自然流量分析。没有搜索词报告时，不输出搜索词、否定词或关键词优化结论。
