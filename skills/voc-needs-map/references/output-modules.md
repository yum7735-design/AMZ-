# Output Modules

Use this file when drafting the final needs-map report.

## Required Modules

Write these modules unless the user explicitly asks for a narrower subset:

1. `用户画像（Persona）`
2. `JTBD（用户任务）`
3. `使用场景（Scene）`
4. `使用流程（Workflow）`
5. `功能痛点（Functional Pain）`
6. `页面认知痛点（Communication Pain）`
7. `包装痛点（Packaging Pain）`
8. `决策因素（Decision Drivers）`
9. `情绪需求（Emotional Needs）`
10. `购买驱动（Purchase Drivers）`
11. `页面优化建议（Listing Implication）`

## Recommended Front Sections

Add these before the modules when useful:

- `分析范围`
- `产品范围界定`
- `Core Judgment`

These sections help the reader understand what evidence was used and what product scope is covered.

## Section Guidance

### 用户画像（Persona）

- Rank by share, importance, or evidence strength
- Prefer task roles over vague demographics
- Explain why each role buys this product

### JTBD（用户任务）

- Write the desired result, not the feature
- Rank by priority
- Keep each job actionable for product and listing teams

### 使用场景（Scene）

- List the high-frequency environment, device, or task context
- Show where the product fits well and where it does not

### 使用流程（Workflow）

- Describe the path from selection to final use
- Call out the stage where mistakes happen most often

### Functional Pain / Communication Pain / Packaging Pain

- Keep product defects, listing confusion, and packaging friction separate
- If the same issue appears in two buckets, explain the split clearly

### 决策因素（Decision Drivers）

- Explain what the buyer evaluates before purchase
- Keep this separate from the final emotional trigger

### 情绪需求（Emotional Needs）

- Capture the psychological payoff: safe, professional, worry-free, efficient, etc.

### 购买驱动（Purchase Drivers）

- Explain what finally converts the buyer
- Distinguish this from table-stakes requirements

### 页面优化建议（Listing Implication）

- Map each insight to a listing action
- Typical targets: title, bullet, main image, image 2-7, A+, comparison chart, packaging callout

## Formatting Pattern

Prefer:

- concise paragraphs for judgments
- tables for evidence-heavy sections
- ordered lists for priorities

Each major claim should be traceable to a source file or clearly marked as inference.
