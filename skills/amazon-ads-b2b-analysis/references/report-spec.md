# Amazon 广告专项分析报告结构

Use this outline when the user asks for the full account analysis. Condense only if they explicitly request a short readout.

1. Executive Summary: 5–10 evidence-backed findings; identify largest sales contributor, largest budget consumer, material budget waste, growth opportunity, enterprise performance, enterprise's best format, and SBV vs SB result.
2. SP / SB / SBV / SD: Spend, Sales, Orders, Impressions, Clicks, CTR, CPC, CVR, ACOS, ROAS, Spend share, and Sales share. Explain large/small scale plus high/low efficiency.
3. SB vs SBV: show side-by-side metrics, clear SBV-versus-SB differences, and a conclusion based on the CTR/CVR combinations.
4. Enterprise versus non-enterprise: the same core metrics and scale context.
5. Enterprise × ad type: identify which format performs better for enterprise purchase and which cells have insufficient data.
6. Campaign: top efficient, top inefficient, and A/B/C/D scale-efficiency representatives by SP, SB, SBV, SD, plus enterprise Campaigns.
7. Product / ASIN: join product information by ASIN; list high-value, high-potential, and high-investment/low-efficiency products; produce an ASIN × type ROAS/ACOS matrix.
8. Search terms: high-value, high-potential, high-spend/no-order, high-click/low-CVR, high-CPC/high-value, and guarded negative recommendations. Do not use these metrics to recompute the account totals.
9. Action list: P0/P1/P2, named object, evidence, issue, action, and objective.
10. Budget reallocation: current Spend/Sales share, ACOS, ROAS, assessment, directional budget recommendation, and priority for ad type plus enterprise × type.
11. Finish with one-sentence answers for SP, SB, SBV, SD, enterprise, SB vs SBV, biggest waste, biggest opportunity, product, search term, reduction/negative candidate, and the next budget move.

Use `—` and “无法判断” where the source cannot support a result. State metric definitions and sample-size limits in the report.
