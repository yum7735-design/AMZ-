# JTBD taxonomy and boundaries

## Task types

| JTBD Type | Explicit user goal |
|---|---|
| Repair 修复 | Repair, fix, mend, restore, or reconnect a damaged object. |
| Protect 保护 | Protect or shield an identified object; prevent stated damage, rubbing, wear, or corrosion. |
| Seal 密封 | Seal a connection or keep water/moisture out. |
| Insulate 绝缘 | Cover an exposed conductor, restore insulation, or prevent shorting. |
| Reinforce 加固 | Add strain relief, reinforce a joint, prevent bending, or hold it in place. |
| Connect/Splice 连接/接线 | Splice, solder, crimp, connect, or rewire a circuit. |
| Organize 整理 | Bundle, organize, or manage cables. |
| Identify/Color Coding 识别/颜色区分 | Label, mark, color-code, or distinguish polarity/circuits. |
| Other 其他 | An explicit task outside these categories. |
| Not Mentioned 未提及 | No explicit user task. |

## Do not confuse task and capability

| Review wording | Do not report | Report only if user action is explicit |
|---|---|---|
| “waterproof seal” | 防水 | 密封连接处，防止水分进入 |
| “insulates well” | 绝缘 | 覆盖裸露导体，恢复绝缘 |
| “protects wires” | 保护能力 | 保护线缆免受明确提到的摩擦或损伤 |
| “adhesive-lined / strong” | 胶层 / 强度 | 加固接头或形成应力释放 |

## Examples

- “Used this to repair the cracked end of my charging cable.” → Repair: 修复充电线破损端部，防止损伤进一步扩大。
- “Used it on my boat wiring.” → Handle/protect boat wiring at most; do not infer sealing.
- “Used it on my boat wiring to keep water out.” → Seal: 密封船舶线缆连接处，降低水分进入风险。
- “Added it over the connection to keep it from bending.” → Reinforce: 加固连接处，减少弯折损坏。
- “Used it to label wires.” → Identify/Color Coding: 标识线缆，便于识别。
