# User-need taxonomy

Use these normalized, outcome-led labels when the linked review evidence supports them. The wording names what the user wants to achieve, not how a product should be engineered.

| Need category | Preferred need label | Typical evidence source |
|---|---|---|
| Protection | 为线缆与连接部位提供可靠的机械保护 | Thin, weak, abrasion, inadequate protection |
| Sealing | 在连接部位形成可靠、防潮的密封 | Water/moisture entry, incomplete seal, stated inadequate waterproofing |
| Insulation | 恢复连接部位稳定的外部绝缘保护 | Exposed conductor, insulation failure, shorting risk |
| Repair | 恢复受损线缆或连接部位的外部保护 | Repair task plus damaged cable/jacket evidence |
| Durability | 使用与收缩后保持材料完整，不易撕裂或开裂 | Cracking, splitting, tearing, loss of integrity |
| Temperature Resistance | 受热环境下保持材料完整和保护表现 | Heat damage or deformation to the tubing itself |
| Fit / Compatibility | 适配目标线缆与连接器的尺寸和形状 | Too small, does not fit, hard to slide over connector |
| Fit / Compatibility | 收缩后与连接部位保持稳定贴合 | Oversized/loose fit after shrink |
| Shrinking Performance | 收缩后形成均匀、紧密且稳定的包覆 | Insufficient, uneven, or incomplete shrink |
| Shrinking Performance | 以可控方式完成收缩，避免过长或过高加热 | Difficult/slow shrink or excessive heat requirement |
| Adhesion | 连接部位长期保持牢固粘合 | Adhesive does not bond/flow or tubing lifts away |
| Installation / Usability | 在目标连接部位上易于安装和操作 | Explicit placement, cutting, handling, or installation difficulty |
| Size / Length | 覆盖常用线缆与连接器尺寸的规格选择 | Explicit insufficient size range or gaps between sizes |
| Size / Length | 提供足以完整覆盖连接部位的长度 | Too short to cover target connection |
| Size / Length | 快速清楚识别并选择合适规格 | Unclear size labels or difficult size identification |
| Organization / Storage | 按规格清晰分类、稳定收纳并便于取用 | Mixed, escaping, damaged, or hard-to-use compartments |
| Reliability | 不同产品件之间保持一致的规格和使用表现 | Explicit piece-to-piece variation or pre-shrunk/damaged pieces |

Use `Not Mentioned` if a review contains neither an explicit need nor a concrete pain point that supports a reasonable user-result inference. Do not promote an individual color, brand, or isolated preference into a market need without repeated evidence.
