# JTBD task taxonomy

Use JTBD only for an explicit user goal. Describe it as an object, an action, and the intended result.

| Type | Use when the review explicitly says the user is trying to | Example job form |
|---|---|---|
| Repair | repair, fix, mend, restore, or reconnect a damaged object | 修复受损电源线外皮，恢复正常使用。 |
| Protect | protect, shield, or prevent stated wear, rubbing, damage, or corrosion | 保护线缆免受摩擦，避免持续磨损。 |
| Seal | seal a connection or keep water/moisture out | 密封船舶连接处，降低水分进入风险。 |
| Insulate | insulate a wire, cover an exposed conductor, or prevent shorting | 覆盖裸露导体，恢复外部绝缘保护。 |
| Reinforce | reinforce, add strain relief, prevent bending, or hold an object in place | 加固充电线端部，减少弯折损坏。 |
| Connect/Splice | splice, solder, crimp, connect, or rewire a circuit | 完成车辆线路拼接，使线路可继续使用。 |
| Organize | organize, bundle, or manage cables | 整理线缆，便于后续管理。 |
| Identify/Color Coding | label, mark, color-code, or distinguish polarity/circuits | 标识线缆，便于识别线路或极性。 |
| Other | explicit task outside these types | 处理绳端以防止散开。 |
| Not Mentioned | no explicit task | 未提及 |

Do not convert “waterproof”, “insulation”, “adhesive”, “protection”, “durable”, or “shrinks well” into a task without an explicit user action or desired outcome. A review saying “used it on boat wiring” supports handling/protecting boat wiring at most; it does not alone support sealing or waterproofing.
