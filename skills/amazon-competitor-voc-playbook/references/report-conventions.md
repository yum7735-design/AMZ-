# HTML competitor playbook conventions

Create a standalone, responsive HTML file with no dependency on external JavaScript or stylesheets.

## Required components

- Hero with ASIN, marketplace, collection date, and sources.
- A compact evidence-first executive conclusion.
- Product image only when a public PDP image URL is available.
- Tables for product profile, keyword/rank evidence, VOC, and opportunity matrix.
- A clear source/conflict note stating which metrics are estimates, which are scores, and which are direct marketplace observations.
- A final text flywheel in which each node has 【事实】, 【推断】, or 【假设】.

## Presentation rules

- Make long tables horizontally scrollable on small screens.
- Use visually distinct labels for facts, inferences, hypotheses, recommendations, and unavailable data.
- Do not use charts for a metric whose denominator, period, or sampling is uncertain.
- Keep quotes short and attribute them to a review record ID, not a reviewer identity.
- Return an absolute clickable path after verifying the file exists.
