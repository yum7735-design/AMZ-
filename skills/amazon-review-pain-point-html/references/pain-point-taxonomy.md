# Pain-point taxonomy

Use one normalized label for the same underlying issue. Do not attach a category merely because a product capability is mentioned.

| Category | Normalized labels | Classification note |
|---|---|---|
| Shrinking Performance / 收缩性能 | Insufficient Shrink / 收缩不充分; Uneven or Incomplete Shrinking / 收缩不均或不完全; Difficult or Slow Shrinking / 收缩困难或缓慢 | Require a negative performance result or explicit difficulty. |
| Adhesive / Sealing / 胶层与密封 | Poor Adhesive Bonding / 胶层粘合不足; Adhesive Does Not Flow / 胶层流动不足; Excessive Adhesive or Glue Mess / 胶层过量或溢胶; Incomplete Seal / 密封不完整 | “Adhesive melts well” is positive, not a pain point. |
| Size / Fit / 尺寸与匹配 | Too Small or Does Not Fit / 尺寸过小或无法匹配; Too Large or Loose Fit / 尺寸过大或包覆松动; Difficulty Fitting Over Connector / 难以套过连接器; Insufficient Size Variety / 规格覆盖不足 | Explicit reviewer admission of buying wrong size is `User Selection Issue`. |
| Physical Durability / 物理耐久 | Tears or Cracks Easily / 易撕裂或开裂; Insufficient Physical Protection / 物理保护不足; Excessive Rigidity / 收缩后过于僵硬 | Do not count “does not tear/crack” or a broken storage case here. |
| Heat / Temperature / 耐温表现 | Heat Damage or Deformation / 受热损坏或变形 | Require damage to the tubing itself; an adhesive melting normally is not heat damage. |
| Installation / Usability / 安装使用 | Difficult Installation or Handling / 安装或操作困难; Difficult to Cut / 难以裁切; Difficult to Position / 难以定位 | Do not convert permanent-installation suitability into a difficulty unless the reviewer expresses a problem. |
| Waterproof / Environmental Protection / 环境防护 | Water Ingress / 进水; Inadequate Waterproofing / 防水能力不足 | Use `Water Ingress` only for confirmed water/moisture entry. Use `Inadequate Waterproofing` for an explicitly inadequate rating or expectation without entry. |
| Length / Quantity / 长度与数量 | Too Short / 长度不足; Insufficient Quantity / 数量不足; Inconsistent Length / 长度不一致 | Keep an advertising or listing-length discrepancy separately where it is not an in-use failure. |
| Packaging / Organization / 包装与收纳 | Poor Packaging Organization / 包装收纳不良; Packaging Damage / 包装损坏 | Packaging/organization is low severity unless it prevents normal use. |
| Labeling / Size Identification / 尺寸识别 | Unclear Size Identification / 尺寸识别不清; Poor Labeling / 标识不清 | Require unclear or missing markings, not merely label mention. |
| Product Consistency / 产品一致性 | Product Consistency Issue / 产品一致性问题 | Require variation across pieces, duplicate/missing declared pieces, or pre-shrunk/damaged pieces. |

Use `Other` only when a real, evidence-backed product-use issue does not fit the taxonomy. Do not label vague dissatisfaction (“not up to expectations”) as `Other` without a specific problem.
